Flash Magpie Buddy

Writes the firmware to an M5Stack CoreS3 over USB-C. It takes about a minute, and wipes whatever was on the board.

This browser cannot flash a board.

Web Serial is only in Chrome and Edge on a desktop. On Safari, Firefox or a phone, use the command line instead:

pio run -t upload

Choose “Erase device” when it asks. The board keeps its Wi-Fi network in flash, and a stale one from another board is worse than none.

After flashing

  1. The board restarts and raises an access point called Magpie-Buddy-XXXX, with the name on its screen.
  2. Join it from your phone. The setup page opens by itself; if not, go to 192.168.4.1.
  3. Pick your network and enter the password. The board saves it and restarts onto your Wi-Fi.
  4. Run the bridge on the machine with magpie: node bridge/magpie-display.mjs --discover

The board finds the bridge by itself over the network, so nothing needs the board's address typed into it.
